🏅 Olympics Data Analysis 

An interactive data analysis dashboard built with Python, Pandas, Matplotlib, and Streamlit to explore Olympic Games history, medal records, participating nations, and athlete performances.

📌 Project Overview

The Olympics Data Analysis Dashboard provides meaningful insights into Olympic Games data through interactive tables, charts, and visualizations. Users can explore overall Olympic trends, analyze individual countries, and discover the achievements of successful athletes.

This project demonstrates practical skills in data cleaning, exploratory data analysis (EDA), data visualization, and interactive dashboard development.

🚀 Features
1. 🏆 Medal Tally
View medal counts for different countries.
Filter medal records by Olympic year.
Compare Gold, Silver, Bronze, and Total medals.
2. 📊 Overall Analysis
Analyze the number of participating nations over the years.
Explore the number of Olympic events across different years.
Study the growth of athlete participation.
Visualize overall Olympic trends using charts.
3. 🌍 Country-wise Analysis
Select a country to explore its Olympic performance.
Analyze medal-winning sports across different years.
View country-wise medal trends.
Identify the sports in which a country has participated and won medals.
4. 🥇 Athlete-wise Analysis
Explore the most successful Olympic athletes.
Analyze athlete medal counts.
View athlete performance by sport and country.
🛠️ Technologies Used
Python — Programming language
Pandas — Data cleaning and data analysis
NumPy — Numerical operations
Matplotlib — Data visualization
Streamlit — Interactive dashboard development
